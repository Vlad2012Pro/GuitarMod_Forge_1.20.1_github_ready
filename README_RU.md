# Guitar Mod — заготовка для Forge 1.20.1

Это стартовый проект, а не законченный релиз. Он содержит предмет-гитару, клавишу G,
окно выбора MP3/WAV/OGG, чтение аудио через Java Sound SPI и простую передачу PCM
пакетами другим игрокам в радиусе 20 блоков.

## Сборка
**GitHub Actions:** загрузи содержимое папки в репозиторий (файл `build.gradle` должен лежать в корне).
Сборка запустится сама при push; готовый JAR — во вкладке Actions → выбери запуск → Artifacts → `guitarmod-jar`.
Запустить вручную можно через Actions → Build mod → Run workflow.

**Локально:** JDK 17, затем `./gradlew build` (Windows: `gradlew.bat build`). JAR будет в `build/libs/`.

## Важно — ограничения прототипа
- Передача звука пока реализована как черновой PCM-relay; перед запуском на публичном
  сервере нужны ограничения частоты/размера, проверка владения предметом, контроль
  одновременных потоков и обработка отключения игроков.
- В этом прототипе удалённый звук воспроизводится через системный аудиовыход Java Sound,
  поэтому он НЕ имеет позиционного затухания/панорамирования и не следует за игроком
  как настоящий Minecraft SoundInstance. Это следующий этап.
- Анимация рук и модели пока не подключена. Текущий JSON предмета — временная заглушка; текстура из файла уже положена в resources.
- MP3/OGG-поддержка зависит от Java Sound SPI и доступности их зависимостей на клиенте.
- Для корректного отображения твоей 3D-модели нужно экспортировать модель из Blockbench
  в Minecraft Java Item/Block JSON и заменить `assets/guitarmod/models/item/guitar.json`,
  а текстуру положить в `assets/guitarmod/textures/item/guitar.png`.
- В исходном `Gitara2.bbmodel` обнаружено 98 элементов, 2 группы и одна встроенная текстура;
  display-настройки присутствуют для обеих рук от первого и третьего лица.
- Не загружай на сервер музыку, на распространение которой у тебя нет прав.

## Управление
- Держи гитару в основной или второй руке.
- Нажми G — откроется музыкальное меню.
- «Загрузить музыку» — выбери MP3/WAV/OGG.
- «Стоп» — остановить локальный трек и отправить событие остановки.

## Статус
Код — демонстрационная основа, не проверенный в запущенном Minecraft проект.
